# core-io exceptions: files of a crate that must not do I/O (its Crates-table row in
# ARCHITECTURE.md lists fs, process or any I/O under "Never depends on") that may still reach
# std::fs, std::net, std::process, std::env, std::time::Instant::now or
# std::time::SystemTime::now. Read by xtask/src/checks/core_io.rs.
#
# Format: one repo-relative file path per line, then whitespace, then why the file is exempt.
# Blank lines and lines starting with # are skipped. A listed path that is not a file fails.
#
# Example (not an entry):
#   crates/protocol/src/fixtures.rs  reads test fixtures from disk
