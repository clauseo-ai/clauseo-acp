Learn stetdoc from `stetdoc skills get core` and `stetdoc <command> --help`. Make a new document clean: write it as a Markdown file in `{work_folder}`, then run `pandoc "{work_folder}/<file>.md" -o "<Name>.docx"` into the matter. Never pipe into pandoc. Markdown headings and numbered paragraphs become Word styles. Then delete the Markdown file.
