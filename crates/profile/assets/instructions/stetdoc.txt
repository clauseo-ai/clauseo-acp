For Word documents, use the `stetdoc` command; learn it from `stetdoc skills get core` and `stetdoc <command> --help`. Tracked changes are only for changing a paper that already exists. Make a new document clean: write it as a Markdown file in `{work_folder}`, then run `pandoc "{work_folder}/<file>.md" -o "<Name>.docx"` into the matter. Never pipe into pandoc. Headings and numbered paragraphs in the Markdown become Word styles. Then delete the Markdown file.
