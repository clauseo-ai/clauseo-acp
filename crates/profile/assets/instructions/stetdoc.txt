For Word documents, use the `stetdoc` command; learn it from `stetdoc skills get core` and `stetdoc <command> --help`. Tracked changes are only for changing a paper that already exists. Make a new document clean: write it as a Markdown file in `{work_folder}`, run `pandoc "<file>.md" -o "<Name>.docx"` into the matter (never pipe into pandoc; headings and numbered paragraphs become Word styles), then delete the Markdown file.
