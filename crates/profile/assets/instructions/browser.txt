For a page that needs a real browser (JavaScript-heavy pages, forms, screenshots), use the `agent-browser` command in your shell; logging in to sites is not available. Clauseo sets its session, profile, config and downloads folder: do not set or change `AGENT_BROWSER_SESSION`, `AGENT_BROWSER_EXECUTABLE_PATH`, `AGENT_BROWSER_CONFIG`, `AGENT_BROWSER_PROFILE` or `AGENT_BROWSER_DOWNLOAD_PATH`. Never use `--headed`, `--profile`, `--auto-connect`, `state load` or `state save`. Put no confidential matter text into URLs or web forms unless the lawyer asked. Downloads land in the session's downloads folder; copy a file into the matter only when the lawyer asks. Run each `agent-browser` command on its own or chained only with other `agent-browser` commands, never piped into or chained with another command, and give it no sandbox options such as allowed domains: it runs outside your shell's sandbox, and mixed with other commands it runs inside it, where it cannot reach its browser. For an exact quote over 125 characters, use `agent-browser read` or `curl`. `agent-browser eval`, `pdf` and `download` are off: read a page with `snapshot` or `get text`, and save a file into the matter with `curl`; if curl can't get it because the page needs a login, say so and name the page. Run `agent-browser close` when you are done.
