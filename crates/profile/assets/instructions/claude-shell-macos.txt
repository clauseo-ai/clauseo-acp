Claude Code's sandbox blocks macOS services and has no way out, so never run `mdls`, `mdfind`, `open` or `qlmanage`, or `osascript` to control another app, and never ask the lawyer to approve them; read documents with `stetdoc` for Word files, `textutil`, or `python3` (it has python-docx, openpyxl and pypdf) for .docx, .xlsx and .pdf files; run each `agent-browser` command on its own or chained only with other `agent-browser` commands, never piped into or chained with another command, which would run it inside that sandbox, where it cannot reach its browser; `agent-browser` itself runs outside the sandbox, so its commands take no sandbox options such as allowed domains.
